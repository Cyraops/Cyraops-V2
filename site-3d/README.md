# CyraOps — interactive site (local development)

A light-palette, highly interactive rebuild of cyraops.com. This runs **locally only**;
nothing here is published. Production is untouched.

## Run it

```bash
cd site-3d
npm install      # once
npm run dev      # http://127.0.0.1:3100
```

## Structure (multi-page, not one scroll)

- **Top nav**: Industries · Expertise · Products · Solutions · Platform · About · Resources, each a
  mega-menu panel. Hover or click to open, Escape to close, arrow between triggers without closing.
  Content is generated from `src/data/nav.ts`, so a new offering appears in the menu automatically.
- **Routes** (hash router, no server rewrite needed):
  `#/` home · `#/<axis>` index · `#/<axis>/<offering>` detail · `#/catalogue` all 39 ·
  `#/about`, `#/about/how`, `#/about/engagement`, `#/about/faq` · `#/contact`
- **39 offering detail pages** with breadcrumbs, what-it-is, capabilities, engagement aside and related links.
- **Footer**: four catalogue columns plus company/elsewhere, matching the convention.

## What is here

- **Six catalogue axes** (39 offerings) in `src/data/catalog.json`, generated by
  `node merge-content.mjs` from the agent-written JSON in `/tmp/site-content`.
  Re-run that script whenever the source JSON changes.
  - Solutions (10) · Products (5) · AI Foundation (6) · Enterprise AI (7) ·
    Functions (6) · Industries (5)
- **Hero** — a WebGL particle tide (react-three-fiber), ink on paper, pointer-reactive
  and scroll-linked. Desktop only: phones get the gradient fallback because 240 KB of
  WebGL fighting the headline is a bad trade.
- **Interactions** — Lenis smooth scroll, magnetic custom cursor, IntersectionObserver
  nav highlighting, scroll-reveal on every block, accordion catalogue with hover states.
- **Accessibility** — skip link, real landmarks, `aria-expanded` on the accordions,
  full `prefers-reduced-motion` path that disables Lenis, the cursor and the canvas.

## Before production

1. Swap the contact link for the real endpoint (`/api/public/inquiries` on the app).
2. Add `robots.txt`, `sitemap.xml`, OG image and JSON-LD.
3. Prerender the catalogue so all 39 offerings exist in HTML for crawlers.
4. Point `/` at this build (see `marketing-source/DEPLOYMENT.md` in the parent repo).
